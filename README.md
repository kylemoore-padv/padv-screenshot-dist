# padv-screenshot-dist

Self-hosted update channel for the **PADV Screenshot** Chrome extension
(ID `aeeebkhiicfiocenkcegogcffokclpbg`). Contains only the signed CRX files and `update.xml`,
served by GitHub Pages at https://kylemoore-padv.github.io/padv-screenshot-dist/update.xml.
Published by `scripts/build_and_publish.sh` in the private source repo.
